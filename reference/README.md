# Reference sources

`uiCA/` contains the Python files of the reference that wuica is a port of: [jtl06/uiCA](https://github.com/jtl06/uiCA), branch
`perf`, commit `8f24bd3` (AGPL-3.0, like this repository). They are here to be read next to the Rust code and are not run from
here (running them needs uiCA's `setup.sh`: the XED module and the instruction tables). All fixtures were exported from this commit.
