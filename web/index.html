What is this / limitations

what

wuica predicts how many CPU cycles one iteration of a block of x86-64 machine code takes on a given microarchitecture, by simulating the pipeline (front end, renamer, scheduler, execution ports) the way uiCA does. It runs entirely in your browser: the code you enter is not sent to a server, and the page works offline after the first visit.

loops

If the block ends in a branch, it is analyzed as a loop (the branch is taken every time). Otherwise it is analyzed as if it were repeated back to back (unrolled).

assumptions

Predictions assume that all data is in the L1 cache and that no branch is mispredicted.

experimental

The models marked experimental (AMD Zen 3, Alder Lake P-core, Ice Lake server) come from a fork of uiCA and are less validated than the stock Intel models.

not official

This is an independent port and not the official uiCA; that is uiCA.uops.info. Results can differ from uiCA's where the port has bugs.
